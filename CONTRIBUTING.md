# Contributing

Contributions are welcome through pull requests. Explain the problem, preserve the skill entry point and renderer interface, and include the checks you ran. Discuss larger changes in an issue first.

Issues should contain the version or commit, Python and Playwright versions, browser, operating system, safe URL details, expected behavior, actual behavior, and reproduction steps. Do not include private URLs, cookies, credentials, or generated private documents.

Security reports belong in [SECURITY.md](SECURITY.md), not public issues.
